# Personalised Skill-Gap and Learning-Path Support

> CSC649 Assignment 1 proposal: a fuzzy expert-system improvement for career skill-gap support in the MYFutureJobs context.

## Status

Draft - repository is private while the assignment is being prepared.

## Problem

Students and early-career job seekers may know their target career and may see required skills, but they may not know what to learn first, which tools to use, or what prerequisites are needed. This project proposes a small, explainable learning-path improvement for the MYFutureJobs career-path context.

## Specialised technology

Fuzzy Logic and Expert Systems
